# harshtheskills

Claude Code skills.

| Skill | What it does |
|---|---|
| [`minimal-impact-change`](minimal-impact-change/) | Surgical, backward-compatible code changes: scope plan, targeted edits, focused verification, final impact audit, plus guard hooks that block or flag risky edits. |

## Install

Copy a skill folder into `~/.claude/skills/` (personal, all projects) or `<repo>/.claude/skills/` (that project only):

```bash
git clone https://github.com/harshshah-2023/harshtheskills.git
cp -r harshtheskills/minimal-impact-change ~/.claude/skills/
```

Each skill's README has its own activation notes and requirements.
